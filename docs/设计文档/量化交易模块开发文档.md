## 核心类与接口

### 1. 数据管线

#### BaseDataProvider (`quant/data/providers/base.py`)
```python
class BaseDataProvider(ABC):
    name: str = "base"
    priority: int = 0

    @abstractmethod
    def get_hist(self, ticker: str, start_date=None, end_date=None, days=252) -> pd.DataFrame: ...
    def supports(self, ticker: str) -> bool: ...  # 覆盖以按市场过滤
```

#### DataPipeline (`quant/data/pipeline.py`)
```python
class DataPipeline:
    def __init__(self):                # 按 priority 排序 providers
    def get_hist(ticker, start, end, days, use_cache=True) -> pd.DataFrame
    def get_batch(tickers, start, end, days) -> dict[str, pd.DataFrame]

# 单例
get_pipeline() -> DataPipeline
```

### 2. 因子引擎

#### BaseFactor (`quant/factors/base.py`)
```python
class BaseFactor(ABC):
    name: str = ""
    category: str = "uncategorized"
    params: dict = {}

    @abstractmethod
    def compute(self, df: pd.DataFrame) -> pd.Series: ...
    def required_columns(self) -> list[str]: ...
    def run(self, df: pd.DataFrame) -> FactorResult: ...
```

#### FactorRegistry (`quant/factors/registry.py`)
```python
class FactorRegistry:
    @classmethod
    def register(cls, name: str): ...        # 装饰器
    @classmethod
    def get(cls, name: str) -> BaseFactor: ...  # 获取实例（缓存）
    @classmethod
    def list_factors(cls) -> list[str]: ...
    @classmethod
    def compute_all(cls, df, factor_names=None) -> dict[str, FactorResult]: ...
```

## API 端点详解

### `GET /api/quant/strategies`
返回预置策略列表。
```json
{
  "strategies": [
    {"name": "ma_golden_cross", "description": "MA5 上穿 MA20...", "condition_text": "...", "threshold": 0.5, "action": "buy"}
  ]
}
```

### `POST /api/quant/backtest`
运行策略回测。

请求体：
```json
{
  "strategy": { "name": "test", "condition_text": "rsi_14 < 30", "threshold": 0.5, "action": "buy" },
  "tickers": ["SH600519"],
  "initial_cash": 100000,
  "start_date": "2024-01-01",
  "end_date": "2025-12-31"
}
```

### `POST /api/quant/portfolio/optimize`
组合优化。

请求体：
```json
{
  "tickers": ["SH600519", "SZ000001", "SH600036"],
  "method": "max_sharpe",
  "max_weight_per_asset": 0.2
}
```

返回权重、预期收益、波动率、夏普比率、有效前沿、相关性矩阵。

### `GET /api/quant/signals?ticker=SH600519&strategy_name=ma_golden_cross`
扫描信号，返回触发信号列表。

### `GET /api/quant/factors?ticker=SH600519`
获取最新因子值。
```json
{
  "ticker": "SH600519",
  "date": "2026-04-25",
  "factors": [{"ticker": "SH600519", "factor_name": "rsi_14", "value": 45.2}, ...]
}
```

## 使用示例

### 后台：运行一个回测

```python
from app.quant.data.pipeline import get_pipeline
from app.quant.signals.presets import PresetStrategies
from app.quant.backtest.engine import BacktestEngine

# 获取数据
pipeline = get_pipeline()
data = pipeline.get_batch(["SH600519", "SZ000001"], days=500)

# 选择策略
strategy = PresetStrategies.ma_cross()

# 运行回测
engine = BacktestEngine(initial_cash=100_000)
result = engine.run(data, strategy)

print(f"累计收益: {result['total_return']}%")
print(f"夏普比率: {result['sharpe_ratio']}")
print(f"最大回撤: {result['max_drawdown']}%")
print(f"胜率: {result['win_rate'] * 100:.1f}%")
```

### 后台：使用 DSL 定义自定义策略

```python
from app.quant.signals.rule import parse_signal_def, evaluate_ast
from app.quant.signals.engine import SignalEngine, Strategy

strategy = Strategy(
    name="my_custom",
    description="自定义超跌反弹",
    condition_text="rsi_14 < 30 AND boll_position < 0.1 AND volume_ratio > 1.5",
    score_weights={"rsi_14": 0.4, "boll_position": 0.4, "volume_ratio": 0.2},
    threshold=0.6,
)

engine = SignalEngine()
signals = engine.evaluate(df, strategy)
```

### 前端：量化中心页面

访问 `http://localhost:5173/quant`，四个标签页：
- **策略管理**：查看预置策略 + 编写自定义 DSL 条件
- **回测分析**：配置参数 → 查看绩效指标和权益曲线
- **组合优化**：输入多个股票 → 查看最优权重和有效前沿
- **实时信号**：按策略扫描当前信号
